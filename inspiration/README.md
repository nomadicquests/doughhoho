# Inspiration

Graphics and videos you like and want our designs to learn from. Nothing in here
is published: it is reference material only.

## How to add something

1. Put the file in the right folder:
   - `graphics/` for images (screenshots, posts, flyers, packaging): `.png`, `.jpg`, `.webp`
   - `videos/` for clips (reels, TikToks, ads): `.mp4`, `.mov`
2. Name it so you can find it later: `who-what.ext`, e.g. `cookieshop-menu-carousel.png`,
   `bakeryx-reel-slowmo-pour.mp4`.
3. Add one line to [`notes.md`](notes.md) saying **what you like about it**. That
   line matters more than the file: "the colours" and "the fast cuts in the first
   2 seconds" lead to very different designs.

Can't download it? Put the link in `notes.md` instead, with a screenshot in
`graphics/` if you can.

## Ways to upload

- **On GitHub:** open the folder, then *Add file → Upload files* (25 MB per file).
- **In a Claude session:** attach the file to your message and ask for it to be
  added here.
- **On your computer:** copy the file into the folder, commit and push.

## Size limits

Keep videos short and under **25 MB** each. Trim to the part you like. GitHub
rejects files over 100 MB, and big videos make the repo slow for everyone. For
longer footage, keep it in Google Drive and put the link in `notes.md`.

## Respecting other people's work

These files are for private reference. We borrow ideas (layout, pacing, mood,
colour approach), never copy someone's actual graphics, photos, music or logo
into a Dough Ho Ho Bakery post.
